Questions fréquentes

Où sont mes notes ?

Dans le dossier que vous avez choisi, sous forme de fichiers Markdown ordinaires. Shokonotes n'en garde aucune copie ni base de données. Ses petits fichiers de réglages (épingles, favoris, symboles de dossiers) sont dans un dossier .shokonotes à l'intérieur de votre dossier de notes.

Comment synchroniser Mac et iPhone ?

Placez votre dossier de notes dans iCloud Drive sur le Mac, puis choisissez ce même dossier sur l'iPhone. Shokonotes n'a pas de serveur.

Peut-on modifier une note dans Shokonotes ?

Sur Mac, vous écrivez dans l'éditeur de Shokonotes ou dans l'éditeur externe de votre choix ; Shokonotes reprend les modifications faites ailleurs dès l'enregistrement. Sur iPhone, vous pouvez capturer de nouvelles notes et modifier une note existante en touchant Modifier. La lecture n'affiche jamais de curseur.

Raccourcis par défaut

  • ⌃⌥⌘N — note rapide dans Inbox, depuis n'importe quelle app
  • ⌃⌥⌘S — afficher ou masquer la bibliothèque, depuis n'importe quelle app
  • ⌘N nouvelle note · ⌘F recherche · ⌘P imprimer · ⌘0 afficher la fenêtre de la bibliothèque

Les raccourcis globaux se changent dans Réglages ▸ Général.

Shokonotes collecte-t-il des données ?

Non. Pas de compte, pas de statistiques, aucun pistage. Voir la politique de confidentialité.

Comment obtenir un remboursement ?

Les achats sont gérés par Apple : demandez un remboursement sur reportaproblem.apple.com.

Configuration requise

macOS 14 ou plus récent, iOS 17 ou plus récent. Un seul achat inclut l'app Mac et l'app iPhone.
