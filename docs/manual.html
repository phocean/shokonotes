Read and Search

The window has three columns: folders and tags on the left, the list of notes in the middle, the note, formatted on the right.

Moving around

  • Click a folder to list its notes and the notes of its subfolders (a setting lets you restrict it to the folder itself).
  • Inbox holds new notes that are not filed yet. All Notes is the whole library. Trash keeps what you deleted until you empty it.
  • With the keyboard: ← and → move between the folders and the list, ↑ and ↓ move inside a column, Space opens or closes a folder.

Search

Press ⌘F (or click the search field) and type. The list narrows while you type, over titles and the full text of every note. Esc clears the search.

Once a note is open, search highlights the words inside it; ⌘G jumps to the next match and ⇧⌘G to the previous one.

Reading is read-only

Selecting, browsing and searching never put you in edit mode. A note changes only when you explicitly open it for writing (see Write).

Pins and favourites

Pin a note to keep it at the top of its list: right-click it, or swipe the row. Folders and tags can be made favourites from their context menu, and a folder can get its own symbol (right-click ▸ Choose Symbol…).

Reading in its own window

To keep a note in view, for example on a second display, choose File ▸ Detach Note for Reading (⌥⌘Return), use the toolbar button, or right-click a note. A window opens with that note, read-only, in your preview theme. It follows the file when it changes or is renamed, and you can go full screen. Close it with ⌘W.

Organise

Shokonotes gives you two ways to sort notes, and they work together.

Folders

A folder is a real folder on your disk. Use them for where a note belongs: one folder per activity, project, or part of your life.

  • ⇧⌘N creates a folder, ⌘R renames the selected note or folder.
  • Drag a note onto a folder to move it, or drag a folder onto another one. The insertion line shows the level the folder will land on.
  • Folders can be nested as deep as you like.

Tags

A tag is a word attached to a note, stored in the note's own header (see below). A note can have several, and tags cut across folders: a recipe can live in Recipes and also be tagged dinner-party.

  • Press ⌃⌘T on a note to edit its tags. Type, press Return or comma to confirm; suggestions come from the tags you already use, to avoid having project next to projects.
  • Click a tag in the sidebar to list every note that carries it.

The Trash

⌘⌫ sends the selected notes to the Trash. A note can be restored to the place it came from, until you empty the Trash.

What a note looks like on disk

A note may start with a small header between two --- lines:

---
title: "Start Here"
tags: [welcome]
created: 2026-10-08
---

It is optional. Without it, the title is the first line of the note (or the file name, depending on your settings) and the note has no tags. Shokonotes only ever rewrites the lines it owns: title, tags and created.

Write

Writing happens in a window of its own, never inside the library.

Open a note for writing

Press Return, double-click a note, or press ⌘N for a new one. Which editor opens is your choice, in Settings ▸ General ▸ Open notes with:

  • Shokonotes' editor — a quiet Markdown editor with colouring, list continuation and code-block completion. Your text is saved continuously: there is no Save button.
  • An external app — Typora, VS Code, BBEdit, TextEdit… Shokonotes picks up your changes the moment the file is saved.

⌘O opens a note in the editor you chose, ⌥⌘O in the other one. Both shortcuts can be changed in Settings.

The editor

  • The title sits at the top; editing it renames the file too: title and file name are the same thing.
  • Tags and the creation date are shown in a small bar above the text.
  • ⌘W closes the editor and returns to the library.
  • The text shown is the real Markdown, symbols included. Markdown Syntax next to this manual shows what each symbol does.

Quick note, from anywhere

Press ⌃⌥⌘N in any app: a new note is created in your Inbox and opens in the editor, without taking you away from what you were doing. You can change the shortcut in Settings.

It works as long as Shokonotes is running, even with its window closed or minimized. To have it ready after every restart, turn on Settings ▸ General ▸ Open Shokonotes at login: the app then starts in the background, without opening its window.

Images

Three ways to add a picture, all from the editor:

  • Drag one or several image files onto the text.
  • Paste a screenshot or a copied image with ⌘V.
  • Click the picture button, or choose Edit ▸ Insert Image… (⇧⌘A).

Shokonotes copies the file into an images folder next to the note and writes the link for you, for example ![holiday](images/holiday.jpg). Your original file is never moved. Names are kept, with a number added if one already exists. ⌘Z removes the link; the copied file stays on disk.

The images folder does not show up in the sidebar unless it contains notes. If you move a note to another folder, move its images folder too: the links are relative to the note.

On iPhone, the picture menu next to Done offers your photo library, the Files app, or pasting an image. Photos are converted to JPEG and their location is removed.

Tables

Writing a table by hand is tedious, so Shokonotes has a small grid editor.

  • Put the cursor in a table and a Edit Table button appears above it. ⌥⌘T and Edit ▸ Edit Table… do the same.
  • Edit ▸ Insert Table… starts a new one.
  • Edit cells, set each column's alignment, add or remove rows and columns. The Markdown that will be written is shown below the grid.
  • Nothing changes in your note until you click Apply, and ⌘Z undoes the whole table in one step.

The table is written aligned, so it stays readable as plain text. Tables inside a list or a quotation, or with a row that has more cells than the header, cannot be edited safely: the editor says why, and you can edit them as text.

On iPhone, the same grid opens from the table menu in the editor header, next to the picture menu.

iPhone and Sync

Shokonotes has no server and no account. Your notes travel the way any file does: through the sync service you already use.

With iCloud Drive

  1. On the Mac, keep your notes folder inside iCloud Drive.
  2. On the iPhone, open Shokonotes, tap Choose Folder… and pick the same folder in iCloud Drive.

The iPhone app is a companion: search, read, and edit a note with the Edit button. A compose button captures a note into the Inbox. In Safari or any other app, Share ▸ Shokonotes saves a page or some text as a note.

Other sync tools

Nextcloud, Syncthing, a Git repository, or nothing at all: on the Mac, any folder works. On the iPhone, only folders in iCloud Drive are supported.

Good to know

  • Rename and organise on the Mac; the phone is for capture and reading.
  • A folder you did not put in iCloud Drive stays on your Mac only.

Customise

Open Settings with ⌘,.

  • General — which editor opens notes, local and global shortcuts, what closing the window does (by default the app keeps running with its global shortcuts), whether Shokonotes opens at login, whether folders list the notes of their subfolders.
  • Storage — the notes folder, how new untitled notes are named, how iCloud conflicts are handled, the file extension.
  • Appearance — the sidebar can be translucent like the rest of macOS, or opaque.
  • Preview — theme, font and size of the formatted note and of the editor.

If the window disappeared

Closing the window does not quit Shokonotes. Bring it back with Window ▸ Library (⌘0), a click on the Dock icon, or the global shortcut ⌃⌥⌘S, which shows and hides the library from any app. Quit with ⌘Q.

Print, export, share

The three buttons at the top right of a note print it, export it as a PDF that looks like the preview, or share the note file (Mail, Messages, AirDrop).

Links and Images

Links

Write the text in square brackets, then the address in parentheses:

[Shokonotes](https://shokonotes.jcbaptiste.com)

Shokonotes

A bare address between angle brackets works too: https://example.com

Images

The same, with an exclamation mark in front. The path is relative to the note, so keep pictures next to your notes:

![A short description](images/photo.jpg)

Why relative paths

Your notes are plain files. If you move the folder to another computer, links to files inside it keep working because they never mention where the folder is.

Code

Put a word in backticks for inline code.

For several lines, fence them with three backticks and name the language. The preview colours it, and the editor does the same.

func greet(_ name: String) -> String {
    "Hello, \(name)!"
}
def greet(name):
    return f"Hello, {name}!"
echo "Hello" > hello.txt

Hover a block in the preview to copy its content with one click.

Lire et chercher

La fenêtre a trois colonnes : dossiers et étiquettes à gauche, la liste des notes au milieu, la note mise en forme à droite.

Se déplacer

  • Cliquez sur un dossier pour lister ses notes **et celles de ses sous-dossiers** (un réglage permet de se limiter au dossier lui-même).
  • Inbox reçoit les nouvelles notes pas encore classées. **Toutes les notes montre toute la bibliothèque. Corbeille** garde ce que vous avez supprimé jusqu'à ce que vous la vidiez.
  • Au clavier : ← et → passent des dossiers à la liste, ↑ et ↓ se déplacent dans une colonne, Espace ouvre ou ferme un dossier.

Chercher

Tapez ⌘F (ou cliquez dans le champ de recherche) puis votre texte. La liste se réduit pendant la frappe, sur les titres et sur tout le texte des notes. Échap efface la recherche.

Une fois une note ouverte, la recherche surligne les mots dedans ; ⌘G va à l'occurrence suivante, ⇧⌘G à la précédente.

Lire ne modifie rien

Sélectionner, parcourir et chercher ne vous mettent jamais en mode édition. Une note ne change que lorsque vous l'ouvrez explicitement pour écrire (voir Prendre des notes).

Épingles et favoris

Épinglez une note pour la garder en haut de sa liste : clic droit, ou balayage de la ligne. Dossiers et étiquettes peuvent devenir favoris depuis leur menu contextuel, et un dossier peut recevoir son propre symbole (clic droit ▸ Choisir un symbole…).

Lire dans sa propre fenêtre

Pour garder une note sous les yeux, par exemple sur un second écran, choisissez Fichier ▸ Détacher la note en lecture (⌥⌘Entrée), utilisez le bouton de la barre d'outils, ou faites un clic droit sur une note. Une fenêtre s'ouvre avec cette note, en lecture seule, dans votre thème d'aperçu. Elle suit le fichier quand il change ou est renommé, et peut passer en plein écran. Fermez-la avec ⌘W.

Classer vos notes

Shokonotes propose deux manières de classer, qui se complètent.

Les dossiers

Un dossier est un vrai dossier sur votre disque. Servez-vous-en pour l'endroit où une note a sa place : un dossier par activité, par projet, par pan de vie.

  • ⇧⌘N crée un dossier, ⌘R renomme la note ou le dossier sélectionné.
  • Glissez une note sur un dossier pour la déplacer, ou un dossier sur un autre. Le trait d'insertion indique le niveau où il atterrira.
  • Les dossiers s'imbriquent à volonté.

Les étiquettes

Une étiquette est un mot attaché à une note, stocké dans l'en-tête de la note elle-même (voir plus bas). Une note peut en avoir plusieurs, et les étiquettes traversent les dossiers : une recette peut vivre dans Recettes et porter aussi repas-entre-amis.

  • ⌃⌘T sur une note ouvre l'éditeur d'étiquettes. Tapez, validez par Entrée ou virgule ; les suggestions viennent de vos étiquettes existantes, pour éviter projet à côté de projets.
  • Cliquez une étiquette dans la barre latérale pour lister toutes les notes qui la portent.

La Corbeille

⌘⌫ envoie les notes sélectionnées à la Corbeille. Une note peut être restaurée à sa place d'origine tant que vous ne videz pas la Corbeille.

À quoi ressemble une note sur le disque

Une note peut commencer par un petit en-tête entre deux lignes --- :

---
title: "Lisez-moi"
tags: [bienvenue]
created: 2026-10-08
---

Il est facultatif. Sans lui, le titre est la première ligne de la note (ou le nom du fichier, selon vos réglages) et la note n'a pas d'étiquette. Shokonotes ne réécrit que les lignes qui lui appartiennent : title, tags et created.

Prendre des notes

On écrit dans une fenêtre à part, jamais dans la bibliothèque.

Ouvrir une note pour écrire

Appuyez sur Entrée, double-cliquez une note, ou ⌘N pour une nouvelle. L'éditeur qui s'ouvre se choisit dans Réglages ▸ Général ▸ Ouvrir les notes avec :

  • L'éditeur de Shokonotes — un éditeur Markdown discret, avec coloration, continuation des listes et complétion des blocs de code. Le texte est enregistré en continu : il n'y a pas de bouton Enregistrer.
  • Une app externe — Typora, VS Code, BBEdit, TextEdit… Shokonotes reprend vos modifications dès que le fichier est enregistré.

⌘O ouvre une note dans l'éditeur choisi, ⌥⌘O dans l'autre. Les deux raccourcis se changent dans les Réglages.

L'éditeur

  • Le titre est en haut ; le modifier renomme aussi le fichier : titre et nom de fichier ne font qu'un.
  • Les étiquettes et la date de création sont dans une petite barre au-dessus du texte.
  • ⌘W ferme l'éditeur et rend la main à la bibliothèque.
  • Le texte affiché est le vrai Markdown, symboles compris. Syntaxe Markdown, à côté de ce manuel, montre ce que fait chaque symbole.

Note rapide, de n'importe où

⌃⌥⌘N dans n'importe quelle app : une nouvelle note est créée dans Inbox et s'ouvre dans l'éditeur, sans vous éloigner de ce que vous faisiez. Le raccourci se change dans les Réglages.

Images

Trois façons d'ajouter une image, toutes depuis l'éditeur :

  • Glissez un ou plusieurs fichiers image sur le texte.
  • Collez une capture d'écran ou une image copiée avec ⌘V.
  • Cliquez le bouton image, ou choisissez Édition ▸ Insérer une image… (⇧⌘A).

Shokonotes copie le fichier dans un dossier images à côté de la note et écrit le lien pour vous, par exemple ![vacances](images/vacances.jpg). Votre fichier d'origine n'est jamais déplacé. Les noms sont conservés, avec un numéro si le nom existe déjà. ⌘Z retire le lien ; le fichier copié reste sur le disque.

Le dossier images n'apparaît pas dans la barre latérale tant qu'il ne contient pas de notes. Si vous déplacez une note dans un autre dossier, déplacez aussi son dossier images : les liens sont relatifs à la note.

Sur iPhone, le menu image à côté de Terminé propose la photothèque, l'app Fichiers ou le collage d'une image. Les photos sont converties en JPEG et leur position est supprimée.

Tableaux

Écrire un tableau à la main est pénible : Shokonotes a donc un petit éditeur de grille.

  • Placez le curseur dans un tableau : un bouton Modifier le tableau apparaît au-dessus. ⌥⌘T et Édition ▸ Modifier le tableau… font de même.
  • Édition ▸ Insérer un tableau… en commence un nouveau.
  • Modifiez les cellules, réglez l'alignement de chaque colonne, ajoutez ou supprimez des lignes et des colonnes. Le Markdown qui sera écrit s'affiche sous la grille.
  • Rien ne change dans la note avant de cliquer Appliquer, et ⌘Z annule le tableau entier d'un coup.

Le tableau est écrit aligné, pour rester lisible en texte brut. Un tableau dans une liste ou une citation, ou dont une ligne a plus de cellules que l'en-tête, ne peut pas être modifié sans risque : l'éditeur dit pourquoi, et vous pouvez le modifier en texte.

Sur iPhone, la même grille s'ouvre depuis le menu tableau de l'en-tête de l'éditeur, à côté du menu image.

iPhone et synchronisation

Shokonotes n'a ni serveur ni compte. Vos notes voyagent comme n'importe quel fichier : par le service de synchronisation que vous utilisez déjà.

Avec iCloud Drive

  1. Sur le Mac, gardez votre dossier de notes dans iCloud Drive.
  2. Sur l'iPhone, ouvrez Shokonotes, touchez Choisir un dossier… et choisissez le même dossier dans iCloud Drive.

L'app iPhone est une compagne : recherche, lecture, et modification d'une note avec le bouton Modifier. Le bouton de rédaction capture une note dans Inbox. Dans Safari ou toute autre app, Partager ▸ Shokonotes enregistre une page ou du texte comme note.

Autres outils de synchronisation

Nextcloud, Syncthing, un dépôt Git, ou rien du tout : sur le Mac, n'importe quel dossier convient. Sur l'iPhone, seuls les dossiers d'iCloud Drive sont pris en charge.

Bon à savoir

  • Renommez et classez sur le Mac ; le téléphone sert à capturer et à lire.
  • Un dossier que vous n'avez pas mis dans iCloud Drive reste sur votre Mac.

Personnaliser

Ouvrez les Réglages avec ⌘,.

  • Général — quel éditeur ouvre les notes, raccourcis locaux et globaux, ce que fait la fermeture de la fenêtre (par défaut l'app continue de tourner avec ses raccourcis globaux), listage des notes des sous-dossiers.
  • Stockage — le dossier de notes, le nom des notes sans titre, la gestion des conflits iCloud, l'extension des fichiers.
  • Apparence — la barre latérale peut être translucide comme le reste de macOS, ou opaque.
  • Aperçu — thème, police et taille de la note mise en forme et de l'éditeur.

Si la fenêtre a disparu

Fermer la fenêtre ne quitte pas Shokonotes. Faites-la revenir avec Fenêtre ▸ Bibliothèque (⌘0), un clic sur l'icône du Dock, ou le raccourci global ⌃⌥⌘S, qui affiche et masque la bibliothèque depuis n'importe quelle app. Quittez avec ⌘Q.

Imprimer, exporter, partager

Les trois boutons en haut à droite d'une note l'impriment, l'exportent en PDF identique à l'aperçu, ou partagent le fichier de la note (Mail, Messages, AirDrop).

Pourquoi des chemins relatifs

Vos notes sont de simples fichiers. Si vous déplacez le dossier sur un autre ordinateur, les liens vers des fichiers qu'il contient continuent de marcher car ils ne disent jamais où se trouve le dossier.

Code

Mettez un mot entre accents graves pour du code en ligne.

Pour plusieurs lignes, entourez-les de trois accents graves et nommez le langage. L'aperçu les colore, et l'éditeur aussi.

func saluer(_ nom: String) -> String {
    "Bonjour, \(nom) !"
}
def saluer(nom):
    return f"Bonjour, {nom} !"
echo "Bonjour" > bonjour.txt

Survolez un bloc dans l'aperçu pour copier son contenu d'un clic.
